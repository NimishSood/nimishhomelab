SIEM HomeLab:
Wazuh + Graylog

Current public scope: a staged SIEM HomeLab with a Wazuh Indexer, Wazuh Dashboard, and Graylog Server on separate Ubuntu Server 24.04.4 LTS VMs in VMware Workstation. The repository documents TLS setup, single-node indexer tuning, dashboard deployment, Graylog 7.0.5 with MongoDB 8.0 and Java 21, truststore configuration for the Wazuh Indexer, and browser verification. The Wazuh Manager, agents, Graylog inputs, and end-to-end alert pipeline are still planned.

Verification and issues

Graylog server deployment

Part 3 records Graylog 7.0.5 deployed on a dedicated VM with MongoDB 8.0, Java 21, generated secrets, and successful web UI login.

TLS truststore setup

The Wazuh root CA was imported into a Graylog-specific Java truststore so Graylog can connect to the Wazuh Indexer over HTTPS.

Backend compatibility correction

Graylog initially saw the backend as Elasticsearch 7.10.2; disabling compatibility.override_main_response_version allowed OpenSearch-compatible detection.

Current limit

The stack is prepared for ingestion, but events are not flowing yet because the Wazuh Manager, agents, and Graylog processing pipeline are not deployed.

Documented architecture

The current public build has three completed VMs. The Wazuh Manager and event-forwarding path are shown as planned work because they are required before alerts can move through Graylog into the Indexer.

Current network: VMware NAT on 192.168.71.0/24. Publicly documented access points include the Wazuh Dashboard at https://192.168.71.103, Graylog at http://192.168.71.101:9000, and Indexer backend access on 9200.

Configuration artifact

This excerpt reflects values documented in the public deployment guides, not local config snapshots.

# Wazuh Indexer
network.host: 192.168.71.100
node.name: wazuh-indexer
cluster.initial_master_nodes: ["wazuh-indexer"]
bootstrap.memory_lock: true
# compatibility.override_main_response_version: true

# JVM sizing
-Xms4g
-Xmx4g

# Wazuh Dashboard
server.host: 192.168.71.103
opensearch.hosts: ["https://wazuh-indexer:9200"]

# Graylog Server
http_bind_address = 0.0.0.0:9000
elasticsearch_hosts = https://graylog:PASSWORD@192.168.71.100:9200
GRAYLOG_SERVER_JAVA_OPTS includes:
-Djavax.net.ssl.trustStore=/etc/graylog/server/certs/cacerts

Part 3 records a TLS hostname/SAN mismatch fix by connecting Graylog to 192.168.71.100 instead of wazuh-indexer, plus the backend compatibility override correction.

Current limitations

  • The single-node Wazuh Indexer has no high availability or replica resilience.
  • The Graylog Server and MongoDB deployment is single-node and suitable for lab learning, not production availability.
  • The Wazuh Manager and agents are not deployed, so there is no live endpoint event collection yet.
  • Graylog inputs, streams, pipelines, forwarding behavior, and retention policy still need to be configured.
  • The Wazuh Dashboard no-server warning remains expected until the manager/API path is implemented.

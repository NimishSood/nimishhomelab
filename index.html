Homelab

Lab infrastructure

The lab runs on Ubuntu Server VMs inside VMware Workstation, with services exposed externally via Cloudflare Tunnels with no open inbound firewall ports. DNS, reverse proxy, and access control are all managed at the Cloudflare layer.

Virtualisation

Ubuntu Server VMs on VMware Workstation. Each service runs in an isolated VM with its own network interface and firewall rules.

Secure external access

Cloudflare Tunnels replace exposed ports. All public subdomains route through Cloudflare's proxy with zero direct inbound exposure to the host network.

Security monitoring

Wazuh Indexer and Dashboard provide endpoint visibility across the lab. Alert rules and detection tuning are ongoing.

Self-hosted services

Plex and Immich run as long-lived services on the lab, covering uptime management, reverse proxy config, and tunnel-connected delivery.

AI / Machine Learning

LLMs, fine-tuning, and applied ML

Alongside security, I run local inference and study model adaptation for problems that connect back to classification, anomaly detection, and malicious pattern recognition.

Local LLM inference with Ollama on RTX 5090

Running Llama 3.1 8B locally on an AMD 7800X3D + RTX 5090 workstation via Ollama. Observing GPU compute utilisation vs VRAM usage at the hardware level (~90% compute load on 8B generation while VRAM stays relatively free). Next: 27B/30B model runs, quantization level comparisons, and multi-model pipeline experiments.

Fine-tuning methodology: LoRA and QLoRA

Studying when fine-tuning is justified versus when RAG or guardrails are the better tool, how training shifts model behavior rather than simply adding knowledge, and why evaluation criteria must be defined before training starts. The goal is to avoid building something that looks good in a demo but fails outside the training distribution.

Security-adjacent ML datasets

Malicious URL Detection (651k labeled URLs) and CIC-IDS-2017 network traffic classification, applying data analysis and ML approaches to real cybersecurity datasets, directly bridging the AI and security tracks.

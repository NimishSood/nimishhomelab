Security data analysis

Malicious URL Detection

Case study GitHub

Problem

Test how far lexical URL features can go before richer signals such as DNS, WHOIS, or page content become necessary.

What I built

Reproducible cleaning, feature engineering, binary and multiclass modeling, and saved evaluation outputs from a Kaggle malicious URLs dataset.

Evidence

651,191 raw rows loaded, 640,792 kept after cleaning, 80,000-row modeling sample, and test metrics saved to CSV for binary and multiclass runs.

What's complete

Exploration, modeling, class-by-class evaluation, and repo-level reproducibility details including hash and run metadata.

What's next

Add richer signals beyond lexical features and test how much the current conclusions hold under a more realistic feature set.

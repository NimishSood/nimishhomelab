 Hackathon / software

CropGuard

Built for the UPEI SMCS Hackathon, CropGuard is a geographically-aware crop disease alert system for PEI that turns isolated reports into coordinated regional response. The README lists Next.js 15, TypeScript, Tailwind CSS, ShadCN UI, Firebase, and Leaflet-based mapping in the implementation.

Hackathon project / 5th Prize
 Data analysis

Malicious URL Detection

An end-to-end exploratory analysis of the Kaggle Malicious URLs dataset (`malicious_phish.csv`) with 651,191 labeled URLs. The README centers the work on reproducible loading, cleaning, class-balance analysis, lexical URL feature exploration, and statistical reasoning.

View GitHub repository
 Security data analysis

Cyber Log Analysis

Explores the CIC-IDS-2017 flow-based network traffic dataset from the Canadian Institute for Cybersecurity. The project focuses on data acquisition, dataset structure, label inspection, feature distributions, class imbalance, and reproducible analysis workflows.
